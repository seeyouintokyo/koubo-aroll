# PRD：koubo-aroll 口播口令粗剪

## 问题

中文口播要一条条删废片。拍摄时用固定口令把正片括出来，回来应该直接得到剪映能用的粗剪，而不是一份剪辑工程。

## 口令

- 开口：拍错了。丢掉它之前的内容，也丢掉这句口令。
- 收口：可以保留。只保留两句中间，收口令不进成片。
- 窗口内再次开口：上一段作废，重新开始。
- 未收口：整段丢弃并警告。误收口：忽略。
- 不使用「再来」「这段OK」。默认识别变体只有「拍错啦」。

## 方案

采用本地优先的一条命令：

1. 文件夹里的视频按文件名自然排序。
2. ffmpeg 抽 16 kHz 单声道。
3. 识别成 JSON + SRT。默认 faster-whisper；`OPENAI_API_KEY` 存在时可用 `--stt openai`。已有 JSON 则 `--transcript-dir` 跳过识别。
4. 口令状态机产出保留段，并尽量从字幕里去掉口令。
5. 保留段拼成 H.264/AAC 的 `roughcut.mp4`，字幕重写成成片时间轴的 `roughcut.srt`。

不把 DaVinci / EDL 当主出口。不递归子目录。成片分辨率跟随第一条素材，竖屏不加横屏裁切。刀口默认贴在口令词边界，`--head-pad` / `--tail-pad` 用来收掉尾音。

## 验收

- `pytest` 覆盖成对保留、重来、未闭合、误收口、跨句口令、词级时间、字幕不含口令。
- `koubo-aroll demo` 用颜色证明成片只有三段正片。
- README 写清拍摄、运行和剪映导入。公众号署名 staraiwork。
